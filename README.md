# Portofolio Haris Arief Kamis 2026

Personal portfolio dashboard for Haris Arief Kamis, showcasing expertise as a Retail Data Analyst.

## Features

- **Dashboard**: Professional summary and data visualization.
- **Interactive UI**: Clean, responsive layout built with Tailwind CSS and React.
- **Portfolio Showcase**: Highlights skills, experience, and contact information.

## Tech Stack

- **Framework**: React 19, Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion (framer-motion)
- **Icons**: Lucide-React
- **Charts**: Recharts
- **Backend/API (Server-Side)**: Node.js with Express

## Installation and Setup

1. **Clone the repository** (if you have the source)
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up environment variables**:
   Create a `.env` file based on `.env.example` and fill in necessary keys.
4. **Run in development mode**:
   ```bash
   npm run dev
   ```
5. **Build for production**:
   ```bash
   npm run build
   ```
6. **Start the production server**:
   ```bash
   npm run start
   ```
